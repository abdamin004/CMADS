CMADS Multi-Agent Clinical Decision Pipeline

LangGraph orchestrated 6-stage pipeline with 7 specialised agents. Processes Synthea Gold-layer patient data through parallel analysis, adversarial review, and evidence-based treatment planning.

Pipeline Stage Legend
Stage 1 — Parallel Data Extraction (EHR + Lab)
Stage 2 — Diagnostic Reasoning (adaptive self-critique loop)
Stage 3 — Clinical Reviewer (adversarial verification)
Stage 4 — Diagnostic Refiner (final differential)
Stage 5 — LLM Evaluator (ground truth comparison)
Stage 6 — Treatment Planning (DIRECT matches only)
Gold Data Layer — Synthea patient data (source of truth)
Shared Memory — LangGraph State (TypedDict channels)
