02 · The problem

The old shared state hid the reasoning chain the agents needed to challenge each other.

The Diagnostic agent runs an adaptive critique loop. The Reviewer's job is to challenge the differential it produces — but it could only see the final JSON. The path was gone.

  • Round 1 — confidence 60. anchored on a single lab finding.
  • Round 2 — confidence 72. added missed dx.
  • Round 3 — confidence 78. ✓ stopped. emits final JSON.
  • Reviewer sees only the JSON. Confidence trajectory, rejected hypotheses, anchoring decisions — all gone.
— PIPELINE STATE · BEFORE

5 channels. 3 used.

patient_context · agent_outputs · execution_trace
conflicts · scratchpad

What was missing: a typed timeline of decisions, per-agent scratch space, any cross-session learning. The placeholder shape of memory without the substance.
03 · old memory vs. new memory

Same LangGraph state — every channel now load-bearing, plus three layers above.

04 · architecture

Four tiers, layered on the LangGraph state — accessed through one MemoryManager facade.

05 · inside the run

Tier 1 · Working / Tier 2 · Episodic

— TIER 1 · WORKING MEMORY
PER-AGENT · INVOCATION-LOCAL · IN-STATE

Scratch space inside one agent invocation.

Lives in state.scratchpad[agent_id] — a previously-unused channel that the multi-round Diagnostic agent now uses to track its own confidence trajectory and critique trail across LLM calls.

Cleared at the start of every invocation; never visible to other agents — that role is Tier 2's. 

mm = MemoryManager.from_state(state, self.agent_id)
mm.working.put("confidence_trajectory", [60, 72, 78])
mm.working.append_to("critique_trail",
    {"round": 2, "confidence": 72, "adequate": False})
— TIER 2 · EPISODIC MEMORY
CURRENT RUN · IN-STATE · PERSISTED TO DISK

A typed timeline of decisions and critiques.

New state channel session_memory (append-reducer). Each entry is a Pydantic-validated SessionEvent — critique, confidence_check, decision, lifecycle markers.

The Reviewer reads the Diagnostic agent's trail and challenges the path, not just the destination. The Refiner reads the full timeline plus Tier-3 priors before producing the final differential. 

self._pending_memory_events.append(
  EpisodicMemory.write(
    event_type="critique",
    agent_id=self.agent_id,
    summary=f"Round {n} conf={c} adequate={a}",
    payload={"round": n, "confidence": c}))
06 · beyond the run

Tier 3 · Semantic / Tier 4 · Procedural

— TIER 3 · SEMANTIC MEMORY
CROSS-SESSION · ON DISK · PER-DISEASE

Per-disease aggregate stats, updated by Stage 7.

Lives in data/gold/memory/semantic_memory.json — a small JSON keyed by disease name. Tracks DIRECT/INDIRECT/MISS counts, rank-1 frequency, average primary confidence, observed evidence patterns.

Updated by the new memory_consolidation_node after every patient. Atomic write via tmp-file + replace; recall is case-insensitive; corrupt files degrade to None instead of crashing the run. 

store = SemanticMemory(cfg.SEMANTIC_MEMORY_PATH)
insight = store.recall("Hypertension")
# {runs:14, direct:9, rank1:7, avg_conf:81.2}
store.consolidate("Hypertension", "DIRECT", rank=1, ...)
— TIER 4 · PROCEDURAL MEMORY
LONG-TERM · STATIC · QDRANT (PRE-EXISTING)

NICE guidelines, uniform recall API.

Wraps the existing NICE-guidelines vector store in Qdrant — no new infrastructure, just a uniform recall(query) API symmetric to the other tiers.

Same code path the Treatment agent already used; now reachable from Diagnostic and Reviewer too. Graceful degradation: if Qdrant is unreachable, recall returns [] instead of crashing the pipeline. 

g = mm.procedural.lookup_disease("Hypertension")
# {nice_guideline: "NG136",
#  recommended_drugs: ["ACE-i", "CCB", ...]}
results = mm.procedural.recall("proteinuria", top_k=3)

09 · summary · next steps

Where the feature stands — and the path to scale.

— ARCHITECTURE

4 tiers · 1 facade.

Working / Episodic / Semantic / Procedural — accessed through one MemoryManager. New Stage-7 memory_consolidation_node. Master flag MEMORY_ENABLED.

— IMPLEMENTATION

Clean Python package.

7 modules under src/memory/. Wired into Diagnostic, Reviewer, Refiner, Treatment. 24 unit tests, all pass. Backward-compatible state shape.

— VALIDATION

Clean A/B on Batch 4.

+5 pp DIRECT, +10 pp Found-rate, no time cost. Same model, same judge — only the flag changed. Reproducible via compare_memory_ab.py.

  • Validate at 270-patient cohort scale — quantify per-disease deltas; check whether priors help the weakest categories (CKD staging, plain hypertension).
  • Warm-start the semantic store from the existing 160-patient results so priors kick in from patient 1 of any new run.
  • Test memory × LLM — does the gain hold for Med42 70B or Claude Sonnet, or is it model-specific?
  • Audit recall events in the trace itself, so we can see which prior fired in each agent decision.
