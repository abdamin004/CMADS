2. Disease Selection Filter Python | pipeline/gold.py
Only diseases with lab evidence in Synthea's modules are selected as target diseases. Diseases removed:
  • Anemia — labs normal before diagnosis (Synthea assigns incidentally without CBC evidence)
  • Cerebral palsy — no lab markers, congenital
  • Epilepsy — no EEG in Synthea, no specific labs
  • Osteoporosis — needs DEXA scan, not in labs
  • Pneumonia — no chest imaging findings in labs
  • Osteoarthritis — clinical diagnosis, no lab markers
Diseases kept: CHF, IHD, MI, ESRD, CKD, Diabetes T2, Hypertension, Metabolic Syndrome, Breast Cancer, HIV, Sepsis, Prostate Cancer, Cystitis

10. LLM-as-Judge Evaluation Qwen3 32B via Groq | src/evaluation/llm_judge.py
Compares MAS differential against ground truth using an LLM judge that understands clinical equivalence.
  • Direct match: exact disease found ("ESRD" = "Stage 5 CKD" = "Kidney failure")
  • Indirect match: clinically related disease found ("Diabetic nephropathy" for ESRD target)
  • Miss: disease not found in differential
  • Clinical accuracy score (0-100) per patient
  • Per-diagnosis classification: which diagnoses are direct/indirect/unrelated
80%direct+indirect on verified cohort
~2sper evaluation

Should You Regenerate Patients?

No. The current Synthea data (14,850 patients) is sufficient. The issue was never the number of patients — it was selecting the RIGHT patients with DETECTABLE diseases.

What we learned:

  • Synthea generates labs and conditions independently — labs don't always reflect diseases
  • Only 12% of conditions are encounter-reason confirmed (clinically diagnosed)
  • Some diseases (anemia, osteoporosis, epilepsy) have no lab markers in Synthea
  • The LLM verifier filters to only patients where diagnosis is actually possible

If you want MORE verified patients, run the LLM verifier on the full 786 cohort instead of just 100. This will find more patients with strong evidence. Estimated: ~150-200 verified patients from 786.

Regenerating Synthea with different parameters won't fix the fundamental issue — Synthea's disease modules generate conditions independently of labs. The verifier is the correct solution.
