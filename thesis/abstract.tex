\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Recent literature identifies workflow coordination, not individual
agent capability, as the principal unsolved problem in clinical
multi-agent AI. This thesis presents CMADS, a seven-agent LangGraph
clinical decision support pipeline that targets that problem through
two architectural contributions: a non-destructive Reviewer--Refiner
pattern that lets a critique step rewrite a flawed primary diagnosis
while preserving the original reasoning for audit, and a four-tier
shared-memory subsystem instantiated from the CoALA taxonomy,
combined with a three-phase anti-anchoring protocol that controls
undue influence from retrieved priors.

Evaluation uses an LLM-as-judge protocol on a 160-patient
Synthea-derived cohort that spans eight cardiometabolic disease
families. The eight families bound the evaluation cohort, not the
system: the agents emit free-text differentials and the pipeline is
disease-agnostic in design --- the scope of the evaluation reflects
the disease coverage Synthea can produce with sufficient
pre-diagnosis signal, not a fixed output vocabulary.
With multi-level memory enabled, the pipeline surfaces the correct
diagnosis somewhere in its top-five differential for $\sim 95\,\%$
of the 160 synthetic patients (151/160). On the same 160 patients,
the multi-level memory configuration lifts that found rate over the
single-level baseline on a paired controlled comparison.
The system is built around two engineering properties demonstrated
in this work --- \textbf{explainability} (every agent's reasoning,
memory operation, and retrieved guideline passage is exposed
verbatim in a doctor-facing console) and \textbf{reproducibility}
(every run writes a deterministic execution trace so any number
reported here can be re-derived from the on-disk artefacts) --- and
two further architectural properties (provider-agnostic LLM adapter
and pluggable converter agents for new clinical modalities) whose
demonstration at scale is left to future work.
