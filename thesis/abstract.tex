\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Recent literature identifies workflow coordination, not individual
agent capability, as the principal unsolved problem in clinical
multi-agent AI. This thesis presents CMADS, a seven-agent LangGraph
clinical decision support pipeline that targets that problem through
two architectural contributions: a non-destructive Reviewer--Refiner
pattern that lets a critique step rewrite a flawed primary diagnosis
while preserving the original reasoning for audit, and a four-tier
shared-memory subsystem instantiated after the CoALA taxonomy,
combined with a three-phase anti-anchoring protocol that controls
undue influence from retrieved priors.

Evaluation uses an LLM-as-judge protocol on a 160-patient
Synthea-derived cohort across eight cardiometabolic disease families,
classifying free-text differentials as DIRECT, INDIRECT, or MISS
against hidden ground truth. The pipeline returns a DIRECT match in
73.8\% of cases (Wilson 95\% CI [66.4, 80.0]), a combined
DIRECT-or-INDIRECT found rate of 87.5\%, and ranks the target
condition first in 60.0\% of cases in which it is found. A controlled
160-patient paired memory A/B test (exact McNemar $p = 1.0$ on 49
discordant pairs) shows multi-level memory broadens the candidate
differential (Found rate $91.9\% \to 93.8\%$, MISS rate $8.1\% \to
6.2\%$ on the same patients) without changing primary-diagnosis
precision (DIRECT rate $53.1\% \to 52.5\%$, $-0.6$ pp). A doctor-facing console exposes the
agent chain, memory operations, and retrieved guideline evidence to
support calibrated clinical trust rather than uncritical acceptance
of model output.
