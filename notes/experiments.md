- 2026-05-15 — **Paired McNemar on existing memory A/B** (`batch_4_med42_20.json`, 20 patients). **OFF:** 8/20 DIRECT (40%, Wilson 95% CI [21.9, 61.3]). **ON:** 9/20 DIRECT (45%, [25.8, 65.8]). **Discordant pairs:** 2 OFF-only, 3 ON-only. **Exact McNemar p = 1.0** — the paired data neither confirms nor rules out a memory effect at this size. **Headline:** memory ON is not worse than OFF on DIRECT in the paired data, in contrast to the unpaired 205-vs-100 aggregate (67.8% vs 49.0%). **Refs:** [`scripts/paired_memory_mcnemar.py`](../scripts/paired_memory_mcnemar.py), [`data/gold/paired_memory_mcnemar.json`](../data/gold/paired_memory_mcnemar.json). #experiment #thesis
- 2026-05-15 — **Detectability-gate sensitivity** on a balanced n=30 sample drawn from the rejected band (Qwen3 confidence 60..79) of `cohort_1k_verify_verification_results.json`. **Sampling:** `scripts/sample_rejected.py --seed 42 --per-band 15`. **Pipeline:** standard 7-agent stack, GPT-OSS-120B, output to `mas_results_detectability_sensitivity/`. **Result:** **4/30 DIRECT (13.3%, Wilson 95% CI [5.3, 29.7])**, 17/30 INDIRECT (56.7%, [39.2, 72.6]), 9/30 MISS (30.0%, [16.7, 47.9]); avg pipeline time 125 s/patient. **vs accepted cohort (73.8% DIRECT):** χ² = 40.13, p ≈ 2.4×10⁻¹⁰; Fisher's exact OR = 0.055, p ≈ 5.2×10⁻¹⁰. **Headline:** the ≥80 confidence gate is doing real selection work — the 73.8% DIRECT headline is *conditional on detectability* (a 60.5 pp drop on the rejected band, statistically unambiguous). High INDIRECT rate (56.7%) suggests the pipeline still surfaces clinically related findings on borderline cases. **Refs:** [`scripts/sample_rejected.py`](../scripts/sample_rejected.py), [`mas_results_detectability_sensitivity/`](../data/gold/mas_results_detectability_sensitivity/), [`sensitivity_summary.json`](../data/gold/mas_results_detectability_sensitivity/sensitivity_summary.json). #experiment #thesis
- 2026-04-29 — **Multi-level memory A/B** on `batch_4_med42_20.json` (20 patients · GPT-OSS 120B · Qwen3 32B judge). **Memory OFF:** 8/20 DIRECT (40 %), 80 % found, 19 % rank-1-when-found, 113 s/patient. **Memory ON:** 9/20 DIRECT (45 %), 90 % found, 17 % rank-1-when-found, 114 s/patient. **Headline:** +5 pp DIRECT, +10 pp Found at no time cost; rank-1 within found stays flat → wiring helps detection more than ranking. **Refs:** [`mas_results_baseline_no_mem/`](../data/gold/mas_results_baseline_no_mem/), [`mas_results_with_memory/`](../data/gold/mas_results_with_memory/), [`compare_memory_ab.py`](../docs/progress_presentation/compare_memory_ab.py). #experiment #thesis
- 2026-05-10 — **Improved memory (3-phase + canonicaliser) at N=50** on `batch_4.json`. **Before (case-based 50):** 20/50 DIRECT (40 %), 84 % found, 31 % rank-1-within-found, 118 s/patient. **After (3-phase + disease canonicaliser + MISS-NONE fix):** 26/50 DIRECT (52 %), 98 % found, 27 % rank-1-within-found, 112 s/patient. **Per-patient:** 16 improved, 4 regressed, 30 unchanged. **Headline:** +12 pp DIRECT, +14 pp Found, slightly faster; rank-1-within-found dipped 4 pp because Round-B clean-room sometimes splits Round-A's strong rank. **Caveat:** Qdrant `patient_cases` already contained all 50 batch_4 patients from the prior `case_based_50` run, so this measurement includes same-cohort priors. **Refs:** [`mas_results_improved_50/`](../data/gold/mas_results_improved_50/), [`compare_improved_50.py`](../docs/memory_presentation/compare_improved_50.py). #experiment #thesis
- 2026-05-10 — **Improved memory cold-start at N=50** on `batch_3.json` (held out — Qdrant ∩ batch_3 = 0/50 at run start; only 50 cross-cohort batch_4 priors available). **Result:** 23/50 DIRECT (46 %), 23/50 INDIRECT (46 %), 4/50 MISS (8 %), 92 % found, 37 % rank-1-within-found, 113 s/patient. **Cohort-leakage delta** vs cohort-warmed `improved_50` (52 %, 98 %): −6 pp DIRECT, −6 pp Found — i.e. roughly 6 pp of the headline batch_4 numbers came from same-cohort priors, the rest is genuine algorithm improvement. Rank-1-within-found is **higher** cold (37 % vs 27 %), suggesting cohort priors had been nudging disease family right but rank wrong. **Refs:** [`mas_results_improved_b3/`](../data/gold/mas_results_improved_b3/), [`compare_improved_b3.py`](../docs/memory_presentation/compare_improved_b3.py). #experiment #thesis
- 2026-05-11 — **Multi-level vs single-level memory A/B on batch_3 (cold-start, full N=50)**. Single-level (working-state only, no Qdrant priors) ran on 45 patients freshly + 5 patients reused from prior `mas_results/`. **Single-level (OFF):** 28/50 DIRECT (56 %), 18/50 INDIRECT (36 %), 4/50 MISS (8 %), 92 % found, 76 % rank-1-within-found, 115 s/patient. **Multi-level (ON):** 23/50 DIRECT (46 %), 23/50 INDIRECT (46 %), 4/50 MISS (8 %), 92 % found, 70 % rank-1-within-found (improved_b3 — slight delta from the prior 37 % rank-1 due to using full session traces). **Δ multi − single:** −10 pp DIRECT, +10 pp INDIRECT, 0 pp Found, −7 pp Rank-1. **Headline:** in a cold-start cohort (no same-cohort priors), multi-level memory **regresses DIRECT** by shifting some confirmed matches into INDIRECT — it improves discovery breadth but not precision. The batch_4 +12 pp DIRECT story was almost entirely cohort-leakage. **Refs:** [`mas_results_baseline_b3/`](../data/gold/mas_results_baseline_b3/), [`mas_results_improved_b3/`](../data/gold/mas_results_improved_b3/), `/tmp/compare_b3.py`. #experiment #thesis
