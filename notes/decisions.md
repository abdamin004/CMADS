# Decisions log

One bullet per decision. Date + reason. Tag `#decision`.

- 2026-04-29 — Add **multi-level memory** subsystem (4 tiers: working / episodic / semantic / procedural) on top of the existing LangGraph state. **Why:** supervisor request for shared session context; the previous design exposed only final agent JSONs to downstream agents, hiding the *path* taken to a diagnosis. **Refs:** [`src/memory/`](../src/memory/), [`src/agents/memory_consolidator.py`](../src/agents/memory_consolidator.py), [`tests/test_memory.py`](../tests/test_memory.py); gated by `MEMORY_ENABLED` env var so the before/after experiment is a clean A/B. #decision #thesis
- 2026-05-06 — **Redesign Tier 4** from "Procedural memory · NICE guidelines" to "**Case-Based memory · past patient cases**". **Why:** wrapping a static guideline lookup in a memory tier was a stretch — guidelines are reference knowledge, not memory. A vector DB earns its keep when used for case-based recall: each finished patient's clinical features are embedded (BioLORD-2023) and stored in a new Qdrant collection `patient_cases` with the run's outcome; the Diagnostic agent retrieves the top-K most similar past patients as a Bayesian prior. NICE guidelines stay accessible via `mm.knowledge_base` but no longer count as a memory tier. **Refs:** [`src/memory/case_based_memory.py`](../src/memory/case_based_memory.py), updated [`memory_consolidator.py`](../src/agents/memory_consolidator.py) writes both Tier 3 + Tier 4, updated [`diagnostic.py`](../src/agents/diagnostic.py) reads Tier 4 at the top of build_user_prompt, 11 new unit tests in [`test_memory.py`](../tests/test_memory.py) (35 total). #decision #thesis
